About me

The person behind the docs

I studied linguistics at Bar-Ilan University and moved into technical writing after graduating. Since then I've written for Avaya, NICE Actimize and, through an outsourcing company, for clients including Cynet, BioT, Coralogix, General Motors and Fabric.

Most recently I was the sole writer for Cynet's unified AI-powered security platform. I owned the Help Center, the API documentation and the release content, and I spent a lot of my time making the documentation process itself faster: AI drafting agents, AI-assisted Python export scripts and a docs-as-code rebuild of a recurring partner-guide project.
