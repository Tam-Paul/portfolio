Making documentation faster and easier to maintain

Docs-as-code · MkDocs · Markdown

Rebuilding a 1,100-page partner guide workflow

A technology partner's 1,100–1,300-page guide had to be rebranded for every release, 13 times over two years. The original process went from PDF to Word and back to PDF by hand and took more than a week each time.

I replaced it with a docs-as-code process: the partner's Markdown source, a reusable set of 30–40 search-and-replace terms built with AI assistance, and an MkDocs build. When I moved to a new machine, I set up the build environment again on my own so the process stayed repeatable.

Result

Turnaround dropped from more than a week to 1.5–2 days per release.
